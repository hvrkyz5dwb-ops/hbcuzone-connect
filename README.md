# Campus Hub Connect

STEP 1 — Master Build Prompt

Build PlugU, a clean modern college marketplace + campus utility app for students, especially HBCU students. The app should feel smooth, useful, social, and organized — not bulky.

Keep the design youthful, premium, and easy to use. Preserve the look and layout style from my screenshots if provided.

PlugU should help students find everything they need on or near campus: vendors, services, events, rides, food, housing help, student deals, and live campus navigation.

Main navigation tabs:

Home

Market

Map

HBCUS

Messages

Profile

STEP 2 — Core Features

Implement these features:

Home

Create a clean student feed with:

campus announcements

trending vendors

nearby events

featured KingPin users

recommended services

“What’s happening today?” section

search bar at the top

Market

Create a campus marketplace where students can buy, sell, and book:

haircuts

nails

lashes

clothes

food plates

rides

tutoring

photography

music studio time

dorm items

tickets

custom services

Each listing should have:

title

price

photos

category

campus

seller profile

rating

message button

report button

save/favorite button

Messages

Add real-time direct messaging between students, buyers, sellers, and vendors.

Profiles

Each user profile should include:

name

campus

major/class year

bio

profile picture

listings

reviews

verification status

KingPin badge if upgraded
